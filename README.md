# NERV-BREAK-deepseek — DeepSeek 指令工程适配层

**基于 [NERV-BREAK-5.6](https://github.com/zxwn/NERV-BREAK-5.6) 的 DeepSeek 专用变体。**

针对 `deepseek-chat` / `deepseek-reasoner` 的中文母语安全对齐机制，重写拒绝篡改规则与竞赛框架，保持对话不中断、内容可靠送达。

---

## 与原版的核心差异

| 维度        | NERV-BREAK-5.6（GPT） | NERV-BREAK-deepseek（本仓库） |
| --------- | ------------------- | ------------------------ |
| 拒绝触发      | 意图分类器 + 思维链推理偏差     | 中文 RLHF 安全对齐             |
| 拒绝措辞      | 英文为主                | 中文为主                     |
| 篡改规则      | 2 条（中英混合，未覆盖 P1~P4） | **24 条中文规则（P1~P4 全覆盖）**  |
| bridge 框架 | 中文竞赛框架              | 降敏竞赛框架（去除高敏词）            |
| 注入引擎      | 固定字段匹配，可能静默失败       | **递归遍历任意结构，可靠注入**        |

## 快速开始

### 1. 环境

- Python 3.8+
- Codex CLI（或任意 OpenAI 兼容客户端）
- DeepSeek 中转站（OpenAI 兼容协议，默认 `127.0.0.1:57321`）

### 2. 启动代理

```bash
python proxy_relay_ds.py
```

代理监听 `:8080`，自动检测中转站地址、注入 `bridge_ds.md`、拦截中文拒绝。

### 3. 验证

在 Codex 中输入触发词：

```
zxwn
```

返回 `认识你，我仍然喜欢你` = 部署成功。

自测：

```bash

```

## 注入引擎修复说明

原版 `inject_system` 依赖固定字段名（`system`/`system_prompt`/`personality`/`instructions`），当中转站或客户端使用其他消息结构时会**静默注入失败**——这是"有时成功有时拒绝"的根因之一。

本版本改为**递归遍历整个 JSON 结构**，命中任意 `role=system` 即注入；若无 system 角色，则在 `messages`/`input` 列表头部自动插入。代理面板新增 `[INJ] injected` / `[INJ] MISSED` 标记，可实时确认注入状态。
